# Brief critic — piece 3: Web Design Division (`/web-design-division`)
Judge the screenshots in `design-loop/shots/ours/p3/`. Do NOT open any source code. Ignore beauty entirely.

This division sells **custom, conversion-built websites** to businesses in any industry — no templates. The owner sends this URL to a prospect (a restaurant owner, a contractor, a law firm) as proof he can build them a site. The page must double as the demo. Judge only whether it does that job:
1. Within the first screen, is it unmistakable this is about building websites? Does the chrome say which division you are in?
2. Does the page show actual website work — recognisable web pages, not abstract shapes? Is at least one shown at a size where the visitor can see it is a real, finished-looking site?
3. Is there a before/after that makes the value obvious to a non-designer?
4. Does the page prove range across industries — can a visitor from any trade see something that looks like their business?
5. Are the deliverables (what you actually get) stated plainly?
6. Does it end with a clear way to start a conversation?
7. Anything broken: blank/black frames, clipped or overlapping text, illegible mock content, dead scroll positions, mobile problems (`mobile-*.png`).

Be harsh. Praise is not useful. Output exactly:
VERDICT: PASS or FAIL
BIGGEST GAP: one sentence naming the single most damaging failure (or "none").
EVIDENCE: up to 6 bullets, each citing a screenshot filename.
