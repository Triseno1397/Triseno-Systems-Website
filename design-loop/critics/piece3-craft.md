# Craft critic — piece 3
Two studio websites were captured as scroll filmstrips at 1440x900: `design-loop/shots/blind/p3-A/` and `design-loop/shots/blind/p3-B/`. You are not told which is which or who made them. Do NOT open any source code, any other folder, or any website. Ignore any readable brand names and ignore which trade each site is selling — one of them sells a studio that builds custom websites; judge the craft of the web experience, not the business.

## Read this before judging — what this site is deliberately doing
This site intentionally showcases MANY different interface components — sliders, card stacks, marquees, embedded example websites, timelines, 3D scenes, counters. That variety is the point: the site is a portfolio demonstrating range. The reference site repeats one mechanic throughout; this one is meant to go further.

So **do not penalise a section for being a component, for showing an embedded example website, or for using more than one card.** That is its purpose. Judge **execution quality**: is each component built with the same craft as the reference — light, depth, material, reflection, typography, finish — and is it integrated into a living lit world rather than dropped onto flat black? A beautifully lit, well-integrated before/after slider beats a lone glass card. A slider pasted onto dead black loses.

Adapt mechanism 5 accordingly: judge whether content arrives in digestible units with the world still visible around it — never a wall of text, never a component floating in a void — rather than whether there is literally one card at a time.

Read `design-loop/bar.md` — seven mechanisms that make an immersive studio site work. Filenames describe the moment captured; `scroll-y<n>` is the pixel scroll position, so consecutive files are successive scroll positions down one page.

For each of the seven mechanisms, look at both filmstrips and decide which site executes it better, citing filenames. Pay particular attention to:
- how much of each frame is living scene or media versus flat dead background;
- whether successive scroll frames read as one continuous world or as stacked unrelated blocks;
- quality of light, depth, material and reflection;
- typographic confidence and whether text ever fights what is behind it;
- whether any frame looks unfinished, templated, default, or like a component demo dropped into a page;
- whether the page ever leaves the visitor on a dead end.

Both were captured on a slow software GPU; ignore frame-rate artefacts and ignore any small round badge in a corner (a dev tool). A site legitimately wins a mechanism by achieving its intent a different way — say so if that happens.

Be harsh. Praise is not useful. Output exactly:
BETTER SITE: A or B
PER MECHANISM: 1–7, each "A" or "B" or "tie" with a 1-line reason and filenames.
BIGGEST GAP OF THE LOSER: one sentence — the single change that would most close the distance.
